## The whole pipeline

```text
Microphone ──> capture ──> mono + 16 kHz ──> Listener ─┐
                                                       ├──> Detector ──> Detection
File / app / socket ──> your decode + resample ─────────┘
```

The detector converts every 10 ms audio block into microWakeWord frontend features, evaluates the TensorFlow Lite model, smooths recent probabilities, and reports a match when the configured cutoff is reached.

:::note[Current platform story]
Windows x86-64 works out of the box with a bundled TensorFlow Lite runtime. Linux and macOS builds need a compatible TensorFlow Lite C shared library supplied by the application.
:::

## Five-minute version

```bash
cargo add micro-wakeword
```

```rust
use micro_wakeword::Listener;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut listener = Listener::from_config("wake-word.json")?;

    while let Some(hit) = listener.next_detection()? {
        println!("Heard {} ({:.1}%)", hit.wake_word, hit.probability * 100.0);
    }
    Ok(())
}
```

Your model JSON and `.tflite` file stay together. That is enough to start listening.
